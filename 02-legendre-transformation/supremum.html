为什么勒让德变换需要上确界？

理解 sup_x { px - f(x) } 的真正含义

📐 勒让德变换的完整定义

g(p) = supx { px - f(x) }

这个定义看起来复杂，让我们一步步分解：

  • px - f(x)：对于每个 x，计算 p 乘以 x 再减去 f(x)
  • 对所有 x 求上确界：找出所有 x 中，px - f(x) 的最大值
  • 结果只与 p 有关：变换后的函数 g 只依赖于 p，不再依赖 x

🔍 为什么不能直接用 xp - f(x)？

关键问题：对于给定的 p，哪个 x 能给出最大值？

情况一：凸函数（可以！）

如果 f(x) 是凸函数且可微，那么存在唯一的 x 使得 p = f'(x)，此时：

supx { px - f(x) } = xp - f(x) → 其中 p = f'(x)
✅ 对于凸函数，切线方法完全正确！因为切线总是在函数上方。

情况二：非凸函数（不可以！）

如果 f(x) 是凹函数，切线在函数下方，此时：

对于凹函数：supx { px - f(x) } 不一定等于 xp - f(x)

性质 凸函数 非凸函数
几何特征 函数图像在任意切线上方 有"山峰"和"山谷"

🎯 上确界的真正含义

上确界 vs 最大值

最大值 (maximum)：函数能达到的最大值

上确界 (supremum)：大于或等于所有值的最小数

区别在于：函数可能永远达不到上确界，但可以无限接近它。

为什么用上确界而不是最大值？

例子：f(x) = -x² 在 [-1, 1] 上

supx∈[-1,1] { px - (-x²) } = sup { px + x² }

当 p > 0 时，最大值在 x = 1 处取得

当 p < 0 时，最大值在 x = -1 处取得

使用上确界可以处理定义域受限的情况！

物理直觉：上确界就像问"这个函数最多能达到多高"， 即使实际达不到那个高度，我们仍然可以用它来定义变换。

✨ 总结

切线方法成立的条件

当 f(x) 是凸函数时，勒让德变换可以简化为：

g(p) = xp - f(x)，其中 p = f'(x)

因为对于凸函数：

  • 每个 p 对应唯一的 x 满足 p = f'(x)
  • px - f(x) 在这个 x 处取得最大值
  • 切线恰好接触函数，不会在函数下方

上确界的意义

上确界保证了勒让德变换对所有函数都有定义，

而不仅仅是凸函数。这是数学上的严谨性要求。
