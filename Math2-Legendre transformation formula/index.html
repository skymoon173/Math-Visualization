勒让德变换可视化

什么是勒让德变换？

勒让德变换是一种数学变换，用于将一个函数 f(x) 转换为其共轭表示 g(p)，其中 p = df/dx 是原函数的导数。几何上，它表示原函数切线截距的相反数。

变换定义：

g(p) = sup_x { px - f(x) }

当 f(x) 是凸函数时，上确界由导数条件 p = f'(x) 给出，此时：

g(p) = x p - f(x)

原函数 f(x)

勒让德变换 g(p)

当前点： x = 0

斜率： p = 0

截距： -g(p) = 0

变换值： g(p) = 0

几何直观

在左侧画布上，您可以移动红色点来改变原函数上的切点。对应的切线会实时显示，其斜率为 p，截距为 -g(p)。

在右侧画布上，绿色点显示了变换后的函数 g(p)，其中横坐标为斜率 p，纵坐标为变换值 g(p)。

勒让德变换的本质是将函数从“位置空间”转换到“斜率空间”，保留了原函数的所有信息，但用不同的变量来描述。
