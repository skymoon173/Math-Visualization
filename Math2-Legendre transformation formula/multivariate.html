多元函数的勒让德变换

从一维到多维的推广

📐 多元勒让德变换的定义

g(𝐩) = sup𝐱 { 𝐩 · 𝐱 - f(𝐱) }

其中：

  • 𝐱 = (x₁, x₂, ..., xₙ)：n 维输入向量
  • 𝐩 = (p₁, p₂, ..., pₙ)：n 维斜率向量（梯度）
  • 𝐩 · 𝐱 = p₁x₁ + p₂x₂ + ... + pₙxₙ：点积（内积）
  • ∇f(𝐱) = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)：梯度向量

核心思想

在一元情况下，我们用切线来近似函数。

在多元情况下，我们用切平面（超平面）来近似函数。

勒让德变换将"位置空间"的坐标 𝐱 转换为"梯度空间"的坐标 𝐩。

🔄 从一元到多元的推广

概念 一元函数 f(x) 二元函数 f(x, y)
微分 导数 df/dx 梯度 ∇f = (∂f/∂x, ∂f/∂y)
线性近似 切线：y = f(x₀) + p(x - x₀) 切平面：z = f(x₀,y₀) + p₁(x-x₀) + p₂(y-y₀)
勒让德变换 g(p) = xp - f(x) g(p₁,p₂) = p₁x + p₂y - f(x,y)
条件 p = f'(x) (p₁,p₂) = ∇f(x,y)
几何意义 切线与 y 轴的截距 切平面与 z 轴的截距

📝 步骤总结

  • 选择切点：在多元函数上选择一点 (x₀, y₀)
  • 计算梯度：求偏导数得到梯度向量 𝐩 = (∂f/∂x, ∂f/∂y)
  • 构造切平面：用函数值和梯度构造切平面
  • 求截距：切平面与 z 轴的交点坐标为 -g(𝐩)
  • 得到变换：g(𝐩) = 𝐩 · 𝐱 - f(𝐱)

⚠️ 重要注意事项

凸性要求

与一元情况类似，多元勒让德变换的简化公式：

g(𝐩) = 𝐩 · 𝐱 - f(𝐱)，其中 𝐩 = ∇f(𝐱)

仅在 f 是凸函数 时成立！

本演示中的函数

x² + y² 凸函数 ✅

x² - y² 非凸（马鞍面）⚠️ 鞍点处不适用

2x² + y² 凸函数 ✅

马鞍面的特殊性

对于 f(x,y) = x² - y²（马鞍面）：

  • 在 x 方向是凸的（开口向上）
  • 在 y 方向是凹的（开口向下）
  • 原点 (0,0) 是鞍点：不是极大值也不是极小值
  • px - f(x,y) 可以无限增大，没有最大值！

🔬 物理中的应用

热力学中的勒让德变换

热力学势的变换就是多元勒让德变换的典型应用：

内能 U(S, V, N) → 焓 H(S, P, N)
H = U + PV = U - (∂U/∂V)·V
用 -P 代替 V 作为自然变量

拉格朗日力学 → 哈密顿力学

这是最著名的勒让德变换应用：

拉格朗日量 L(q, q̇, t)
哈密顿量 H(p, q, t) = Σ pᵢ q̇ᵢ - L
其中 pᵢ = ∂L/∂q̇ᵢ
