📐 高斯曲率介绍

高斯曲率（Gaussian Curvature）是曲面在一点处最重要的几何不变量之一。

定义公式
$$K = \\frac{\\det(II)}{\\det(I)} = \\frac{LN - M^2}{EG - F^2}$$

其中 $I = (g_{ij})$ 和 $II = (h_{ij})$ 分别是第一和第二基本形式。

几何意义
  • $K > 0$: 椭圆点，曲面局部像球面
  • $K = 0$: 抛物点或平坦点，可展曲面
  • $K < 0$: 双曲点，曲面局部像马鞍面
高斯著名定理

高斯绝妙定理（Theorema Egregium）

高斯曲率仅由度量张量决定，是曲面的内蕴几何量。

这意味着高斯曲率在等距变换下保持不变！

常见曲面曲率
曲面高斯曲率类型
球面（半径R）$K = 1/R^2$正常曲率
平面$K = 0$零曲率
圆柱面$K = 0$零曲率（可展）
圆锥面（除顶点）$K = 0$零曲率（可展）
双曲面$K < 0$负曲率
