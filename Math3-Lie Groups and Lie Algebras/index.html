李群与李代数可视化

从第一性原理解释数学结构的起源

一、群的基本概念

▼

1.1 群的定义与公理

为什么需要群？

群是描述"对称性"和"变换"的数学语言。它告诉我们：什么样的变换可以组合？什么样的变换有逆操作？

群的公理化定义

群(G, ·)是一个集合G，配备了一个二元运算"·"，满足：

① 封闭性：a·b ∈ G（运算结果仍在群中）

② 结合律：(a·b)·c = a·(b·c)

③ 单位元：∃e ∈ G, e·a = a·e = a

④ 逆元：∀a ∈ G, ∃a⁻¹, a·a⁻¹ = a⁻¹·a = e

整数加法群 (ℤ, +)

• 封闭：a+b仍是整数

• 结合：(a+b)+c = a+(b+c)

• 单位元：0

• 逆元：-a

1.2 矩阵群 GL(n)

为什么研究矩阵群？

矩阵是线性变换的表示。矩阵群描述了所有可逆线性变换，以及它们如何组合。

一般线性群 GL(n)

GL(n) = { A ∈ ℝⁿˣⁿ | det(A) ≠ 0 }

• 运算：矩阵乘法

• 单位元：单位矩阵 I

• 逆元：矩阵的逆 A⁻¹

二、为什么需要李群？

▼

2.1 离散群vs连续群

? 核心问题

离散群（如对称群）只能描述有限种对称性。但现实世界中存在无限连续的对称性（如旋转可以是任意角度），如何描述？

解决方案：引入光滑结构

我们需要一种同时具有：

① 群结构：描述如何组合变换

② 流形结构：描述无限连续的变化

这就是李群！

流形的直观理解

流形 = "局部看起来像欧氏空间"的拓扑空间

• 地球表面是2维流形（局部像平面）

• SO(3)是3维流形（局部像ℝ³）

• 关键：可以在局部定义坐标、导数、积分

2.2 SO(3)的来源

为什么定义SO(3)？

在三维空间中，旋转是最基本的刚体运动之一。SO(3)精确描述了所有保持原点不变的旋转。

SO(3)的定义

SO(3) = { R ∈ ℝ³ˣ³ | RᵀR = I, det(R) = 1 }

• RᵀR = I：保持长度和角度（正交性）

• det(R) = 1：保持手性（不反转空间）

三、反对称矩阵的起源

▼

3.1 问题：如何描述SO(3)的局部变化？

? 为什么会有反对称矩阵？

我们要问：SO(3)中任意一点附近的"切线方向"是什么？这些切线为什么是反对称矩阵？

推导过程

考虑SO(3)中的一条光滑曲线 R(t)，满足 R(0) = I

由于对所有t有 R(t)ᵀR(t) = I，两边对t求导：

⇒ d/dt[R(t)ᵀR(t)] = Ṙ(t)ᵀR(t) + R(t)ᵀṘ(t) = 0

⇒ Ṙ(t)ᵀR(t) = -R(t)ᵀṘ(t)

在 t = 0 处（因为 R(0) = I）：

⇒ Ṙ(0)ᵀ = -Ṙ(0)

结论

SO(3)在单位元处的切空间由满足 Kᵀ = -K 的矩阵组成，这就是反对称矩阵！

3.2 反对称矩阵的结构

3×3反对称矩阵的形式

任意3×3反对称矩阵K可以表示为：

K = [ 0 -k₃ k₂ ]

[ k₃ 0 -k₁ ]

[-k₂ k₁ 0 ]

只由3个独立参数决定！这正是SO(3)是3维流形的原因。

旋转向量 ↔ 反对称矩阵

给定向量 ω = [ω₁, ω₂, ω₃]ᵀ，对应反对称矩阵：

[ω]× = [ 0 -ω₃ ω₂ ]

[ ω₃ 0 -ω₁ ]

[-ω₂ ω₁ 0 ]

这就是 so(3) ≅ ℝ³ 的原因！

四、李括号的起源

▼

4.1 问题：如何在切空间中定义乘法？

? 为什么需要李括号？

群中有乘法运算 G × G → G。李代数作为切空间，如何保持这种"乘法"的结构？

推导：群乘法 → 李括号

考虑两个群元素 g, h 的交换子：

[g, h] = ghg⁻¹h⁻¹

这衡量了g和h的"不可交换程度"。

现在取 g = exp(sX), h = exp(tY)，并在s=t=0处展开：

[exp(sX), exp(tY)] = st[X, Y] + O(s², t²)

其中 [X, Y] = XY - YX 定义了李括号！

结论

李括号 [X, Y] = XY - YX 是群交换子在单位元处的"导数"，它描述了两个切方向的"不可交换程度"。

4.2 为什么需要雅可比恒等式？

? 雅可比恒等式的本质

雅可比恒等式确保李括号与群结构保持一致。它保证了：李括号描述的"不可交换性"在群中是自洽的。

从群结合律推导雅可比恒等式

考虑三个群元素 g, h, k，考虑嵌套交换子：

[g, [h, k]] + [h, [k, g]] + [k, [g, h]]

展开后，所有四次项和更高次项相消，只剩下：

= [X, [Y, Z]] + [Y, [Z, X]] + [Z, [X, Y]]

这必须恒等于0，否则群结构会矛盾！

几何意义

雅可比恒等式的几何含义：

• 考虑三条切向量 X, Y, Z

• 沿X移动，再沿[Y,Z]移动

• 与沿[Y,[Z,X]] + [Z,[X,Y]]移动结果相同

• 这是流形上"平行移动"的自洽性条件

4.3 验证反对称性

从定义直接验证

[X, Y] = XY - YX

[Y, X] = YX - XY = -(XY - YX) = -[X, Y]

✓ 反对称性自然满足！

从几何理解反对称性

如果先沿X再沿Y，与先沿Y再沿X的差异是 [X,Y]

反过来，差异是 [Y,X]

两次差异应该是相反的：-[X,Y]

✓ 这正是反对称性的几何含义！

五、指数映射

▼

5.1 为什么需要指数映射？

连接切空间与流形

李代数（切空间）是线性的，李群（非线性流形）是弯曲的。指数映射告诉我们：沿切方向走多远会到达流形上的哪一点。

从微分方程推导

考虑微分方程：dR/dt = K·R, R(0) = I

解为：R(t) = exp(tK)

这是泰勒展开：exp(tK) = I + tK + (tK)²/2! + ...

当 t = 1 时，exp(K) ∈ SO(3)

Rodrigues公式

给定旋转向量 ω = θ·u（θ为模长，u为单位向量）

R = exp([ω]×) = cos(θ)I + (1-cos(θ))uuᵀ + sin(θ)[u]×

5.2 完整的Rodrigues公式推导

步骤1：反对称矩阵的幂次规律

设 K = [u]×，则 K² = uuᵀ - I（正交性）

K³ = K²K = (uuᵀ - I)K = u(uᵀK) - K = -K

K⁴ = -K² = I - uuᵀ

K⁵ = K

循环周期为4！

步骤2：泰勒展开并分组

exp(θK) = I + θK + θ²K²/2! + θ³K³/3! + θ⁴K⁴/4! + ...

= I + (θ - θ³/3! + θ⁵/5! - ...)K + (θ²/2! - θ⁴/4! + ...)K²

= I + sin(θ)K + (1-cos(θ))K²

步骤3：代入K和K²

K = [u]×, K² = uuᵀ - I

exp(θK) = I + sin(θ)[u]× + (1-cos(θ))(uuᵀ - I)

= cos(θ)I + (1-cos(θ))uuᵀ + sin(θ)[u]×

六、SO(n)的几何形状

▼

7.1 SO(2)：圆周流形

SO(2)是什么？

SO(2)是二维平面上的旋转群，描述了所有保持原点不变的旋转。

SO(2)的定义

SO(2) = { R ∈ ℝ²ˣ² | RᵀR = I, det(R) = 1 }

其中旋转矩阵为：

R(θ) = [cos(θ) -sin(θ)]

[sin(θ) cos(θ)]

几何直观：圆周 S¹

SO(2)的几何形状是一个圆周 S¹：

• 圆周上的每一点代表一个旋转角度 θ

• 角度 θ ∈ [0, 2π)

• θ = 0 和 θ = 2π 是同一点（单位元）

• SO(2)是1维流形

可视化说明

右侧蓝色圆环代表SO(2)流形。

绿色箭头表示当前旋转角度在圆周上的位置。

旋转立方体来观察SO(2)的作用效果。

7.2 SO(3)：实心球流形

SO(3)是什么？

SO(3)是三维空间中的旋转群，描述了所有保持原点不变的3D旋转。

SO(3)的定义

SO(3) = { R ∈ ℝ³ˣ³ | RᵀR = I, det(R) = 1 }

• 维度：3维（3个自由度）

• SO(3) ≅ RP³（实投影3空间）

几何直观：实心球模型

SO(3)可以可视化为一个实心球：

• 球面上每一点代表一个旋转轴方向

• 从原点到该点的距离代表旋转角度 θ

• θ = 0 在球心（单位元，无旋转）

• 球面上 θ = π（最大旋转角度）

• 对径点等同：旋转θ关于轴u = 旋转(2π-θ)关于轴-u

球面点与旋转的对应

球面上点 P = (x, y, z) 对应：

• 旋转轴：u = P / ||P||（方向）

• 旋转角度：θ = π × ||P||（距离）

• 例如：北极点 → 绕Z轴旋转π弧度

为什么是实心球？

SO(3)由3个参数描述（3个自由度）：

• 2个参数确定旋转轴方向（在球面上）

• 1个参数确定旋转角度（从0到π）

这正是3维实心球的结构！

7.3 SO(2)与SO(3)的关系

维度和结构

SO(2)：1维流形 ≅ S¹（圆周）

SO(3)：3维流形 ≅ RP³（实投影空间）

包含关系

SO(2) ⊂ SO(3)

• SO(3)包含绕任意轴的旋转

• SO(2)只包含绕Z轴的旋转

• 在SO(3)中，SO(2)是一个子流形

7.4 更高维度的SO(n)

SO(n)的维度

dim(SO(n)) = n(n-1)/2

• SO(1)：0维（只有单位元）

• SO(2)：1维（S¹）

• SO(3)：3维（RP³）

• SO(4)：6维

• SO(n)：n(n-1)/2维

八、从叉积到反对称矩阵

▼

7.1 问题起源：如何用矩阵表示叉积？

我们知道3D空间中两个向量的叉积：

叉积公式

ω × v = ⎛ ω₂v₃ - ω₃v₂ ⎞

⎜ ω₃v₁ - ω₁v₃ ⎟

⎝ ω₁v₂ - ω₂v₁ ⎠

问题：能否把叉积写成矩阵乘法的形式 [ω]× · v ？

7.2 推导过程

设 [ω]× 是一个 3×3 矩阵，满足 [ω]× · v = ω × v

矩阵乘法展开

⎛ a₁₁ a₁₂ a₁₃ ⎞ ⎛ v₁ ⎞ ⎛ ω₂v₃ - ω₃v₂ ⎞

⎜ a₂₁ a₂₂ a₂₃ ⎟ ⎜ v₂ ⎟ = ⎜ ω₃v₁ - ω₁v₃ ⎟

⎝ a₃₁ a₃₂ a₃₃ ⎠ ⎝ v₃ ⎠ ⎝ ω₁v₂ - ω₂v₁ ⎠

计算第一行：a₁₁v₁ + a₁₂v₂ + a₁₃v₃ = ω₂v₃ - ω₃v₂

匹配系数：a₁₁ = 0, a₁₂ = -ω₃, a₁₃ = ω₂

对其他行做同样推导，得到：

反对称矩阵

[ω]× = ⎛ 0 -ω₃ ω₂ ⎞

⎜ ω₃ 0 -ω₁ ⎟

⎝ -ω₂ ω₃ 0 ⎠

7.3 关键性质：反对称性

观察矩阵的转置：

反对称性证明

[ω]×T = ⎛ 0 ω₃ -ω₂ ⎞

⎜ -ω₃ 0 ω₁ ⎟ = -[ω]×

⎝ ω₂ -ω₃ 0 ⎠

定义：满足 KT = -K 的矩阵称为反对称矩阵

这就是 so(3) 的定义：

so(3)的定义

so(3) = { K ∈ ℝ³ˣ³ | KT = -K }

7.4 为什么会有这个同构？

叉积的基本性质：

• 线性性：a × (b + c) = a × b + a × c

• 反对称性：a × b = -b × a

• 自反性：a × a = 0

莱布尼茨法则：对于旋转矩阵 R(t) = exp(tK)

R 是正交矩阵 (RTR = I) ⇔ KT + K = 0 ⇔ K 是反对称矩阵

直观理解

绕轴 u 旋转无穷小角度 dθ：

R = I + dθ · [u]× + O(dθ²)

• I 恒等变换

• [u]× 无穷小旋转的生成元

• 反对称性保证 R 是正交矩阵

7.5 三维空间的特殊性

维度对比

3维空间：

• so(3) 有 3 个独立分量 (ω₁, ω₂, ω₃)

• 恰好与 ℝ³ 同构！

→ 这就是 ℝ³ ≅ so(3) 的原因

4维空间：

• so(4) 有 6 个独立分量

• 不能用 ℝ⁴ 向量表示

所以这个同构是 3维空间独特的性质！

7.6 总结：推导链

从叉积到李代数

① 叉积 ω × v 是线性的

② 写成矩阵乘法 [ω]× · v

③ 逐项匹配系数，得到 [ω]×

④ 发现 [ω]×T = -[ω]× （反对称）

⑤ 推广：反对称矩阵集合就是 so(3)

⑥ 结论：ℝ³ ≅ so(3)（3维特有）

九、矩阵指数函数

▼

9.1 矩阵指数的定义

问题：矩阵指数 $\exp(A)$ 只是标量指数的类比吗？

答案：不完全是！它有严格的数学定义。

矩阵指数的定义

定义：对于任意方阵 A，定义

$$\exp(A) = \sum_{n=0}^{\infty} \frac{A^n}{n!} = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \cdots$$

其中 $A^n$ 表示 n 次矩阵乘法，$0! = 1$。

为什么可以这样定义？

1. 矩阵的加法和乘法满足结合律、分配律

2. 矩阵范数的完备性保证级数收敛

3. 这不是"类比"，而是泰勒级数在函数空间的自然推广

9.2 从微分方程出发的推导

核心观点：指数函数可以用微分方程定义

标量情况的微分方程

$$\frac{d}{dt}e^{kt} = k \cdot e^{kt}, \quad e^{k\cdot 0} = 1$$

推广到矩阵：

矩阵微分方程

$$\frac{d}{dt}\exp(Kt) = K \cdot \exp(Kt), \quad \exp(K\cdot 0) = I$$

其中 K 是常数矩阵。

物理意义：

• 这描述了一个"流"（flow）

• 起点在 $t=0$ 处的 $I$

• 速度场由 $K$ 决定

• 解这个方程就得到 $\exp(Kt)$

9.3 泰勒级数的严格推导

步骤 1：假设解可以写成幂级数

幂级数假设

$$f(t) = \sum_{n=0}^{\infty} a_n t^n$$

步骤 2：代入微分方程

$$\frac{df}{dt} = K f(t)$$

$$\sum_{n=1}^{\infty} n a_n t^{n-1} = K \sum_{n=0}^{\infty} a_n t^n$$

步骤 3：比较系数

$$a_1 = K a_0$$

$$2a_2 = K a_1 \Rightarrow a_2 = \frac{K^2}{2!} a_0$$

$$3a_3 = K a_2 \Rightarrow a_3 = \frac{K^3}{3!} a_0$$

...

步骤 4：得到通项

$$a_n = \frac{K^n}{n!} a_0$$

步骤 5：由初始条件 $f(0) = I$ 得 $a_0 = I$

最终结果

$$f(t) = \exp(Kt) = \sum_{n=0}^{\infty} \frac{(Kt)^n}{n!}$$

9.4 反对称矩阵的指数展开

对于 $K^\top = -K$，有特殊性质：

奇偶次幂的性质

• $K^1$：反对称矩阵

• $K^2$：对称矩阵（因为 $(K^2)^\top = K^\top K^\top = (-K)(-K) = K^2$）

• $K^3$：反对称矩阵

• $K^4$：对称矩阵

...

规律：奇次幂是反对称的，偶次幂是对称的

分组展开：

奇偶分组

$$\exp(K) = \underbrace{I + \frac{K^2}{2!} + \frac{K^4}{4!} + \cdots}_{\text{对称部分}} + \underbrace{K + \frac{K^3}{3!} + \frac{K^5}{5!} + \cdots}_{\text{反对称部分}}$$

这正是罗德里格斯公式的来源！
