# 李群与李代数可视化

这是一个基于Three.js的全前端网页应用，用于可视化李群和李代数的变换。

## 功能特性

- 3D可视化展示李群变换
- 实时调整X、Y、Z轴旋转角度
- 动画演示李群变换过程
- 支持重置和动画控制

## 技术栈

- HTML5
- CSS3
- JavaScript
- Three.js (3D可视化库)

## 使用方法

1. 克隆或下载项目文件
2. 启动本地服务器：`python -m http.server 8000`
3. 打开浏览器访问：`http://localhost:8000`

## 项目结构

```
├── index.html          # 主HTML文件
├── lie-algebra.js      # 李群与李代数计算模块
├── app.js              # 应用程序主逻辑
└── README.md           # 项目说明文档
```

## 数学模块

### 李群变换

- SO(3) 旋转群
- SE(3) 欧氏变换群

### 李代数计算

- 旋转向量转旋转矩阵 (Rodrigues公式)
- 旋转矩阵转旋转向量
- 四元数转旋转矩阵
- 欧拉角转旋转矩阵 (ZYX顺序)
- 旋转矩阵乘法
- 向量旋转

## 交互控制

- 滑块控制X、Y、Z轴旋转角度
- 重置按钮恢复初始状态
- 动画按钮开始/停止自动旋转
